## Publication boundaries

No additional open-source license grant is invented for original artifacts lacking one. Known third-party skills are not reclassified as user-owned or copied into this repository. The public team harness is retired; official Python/Codex distributions and authentication remain separate dependencies.

Portable copies omit personal machine paths, vault agreements, private policy variants, project receipts and raw conversations. Structural checks, isolated tests, previous acceptance evidence, actual model outputs and fresh automatic discovery are different evidence levels. Test details and unverified runtime scope are stated in the PR. Deferred candidates remain explicit gaps; this inventory is not a declaration of complete publication.

# C4fy Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Deliver an original C4fy renderer, reusable Skill/Plugin, and a verified MacPilot C1/C2/C3 artifact.
**Architecture:** Typed model and semantic validator feed deterministic layout and standalone viewer. The viewer animates hierarchy changes with shared entity IDs.
**Tech Stack:** Node.js built-ins, SVG, CSS, Web Animations; browser tests through available local Chromium tooling.
**Spec:** docs/superpowers/specs/2026-10-25-c4fy-design.md

## Global constraints
- Original implementation; no Archify dependency or fork.
- C1/C2/C3 scope correctness and source evidence; no invented runtime boundaries.
- Cute, readable Korean UI; semantic animated transitions; reduced-motion and last-selection behavior.
- Preserve unrelated work; local creation/install only, no remote publication.

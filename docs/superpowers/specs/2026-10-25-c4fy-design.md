# C4fy

## Intent and decisions
Create an original, independent C4 diagram renderer and discoverable Skill/Plugin. The user superseded the fork request: Archify is a workflow reference only, not a code source or runtime dependency. The user requested a cute diagram UI and smooth C1/C2/C3 transitions. Proceed directly in the existing clean checkout; no publishing or commits are needed for this request.

## Approach
Use Node.js built-ins for model validation, deterministic layout, self-contained HTML generation and SHA-256 delivery receipts. Use original SVG/CSS/JavaScript for the browser viewer. No copied Archify runtime, remote fonts or network dependencies. A thin Archify adapter was considered, then a fork selected, then explicitly superseded by the original implementation request.

C4 model: persons, systems, containers and components have stable IDs, descriptions, parent ownership, technologies and optional source ranges. Context views contain people/systems; container views expand one system; component views expand one container. A filesystem data store is a container; Swift files/modules alone are not. Edges retain action and protocol. Views select actual relationships rather than inventing aggregation. Unknowns and optional paths remain explicit. C4 code-level diagrams are outside this first release.

## UI
Warm ivory canvas, lilac/mint/peach cards, rounded edges and small original line icons. Korean and English UI catalogs, keyboard-accessible view/node controls, responsive diagram plus details, theme toggle, search, fit/zoom, SVG and JSON downloads. No decorative statistics or fabricated facts. Evidence drawer shows selected element's responsibility and source ranges.

Semantic transitions: stable shared IDs move between old/new coordinates; a focused system/container expands into the next view's boundary. New interior nodes emerge near the scope; leaving nodes fade. Back navigation reverses the spatial cue. Last requested view wins during rapid changes. Respect prefers-reduced-motion with immediate view changes. Around 420 ms, no perpetual motion.

## Implementation and acceptance
Portable package c4fy/ with mirror plugins/c4fy/skills/c4fy, manifest and local marketplace entry, README/CHANGELOG and distribution checks. Install standalone under ~/.codex/skills/c4fy after tests. Installed files are not proof of a fresh session's discovery or published marketplace availability.

Validate hierarchy, uniqueness, view scope, visible edge endpoints, source range/path safety, bounded text/coordinates and unknown fields. Escape all user-authored content in HTML/SVG/JSON. Route around unrelated nodes; fail on invalid layout rather than claiming quality. Render atomically without corrupting a previous artifact; receipt binds exact input/output bytes. Browser evidence is separate from model/layout validation and visual judgment.

Test invalid C4 ownership/scope, unsafe text, dangling endpoints, evidence outside repo, output preservation on failure, offline standalone HTML, navigation/animations/reduced motion/rapid selection, keyboard/search/export and desktop/mobile containment. Rebuild MacPilot C1/C2/C3 from pinned repository source, inspect the HTML visually, and retain artifacts and receipts outside source packages.

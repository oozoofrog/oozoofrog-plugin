# 검증 상태

**행동 검증 통과 아님.** 구조 검사는 통과했으나, 확인되지 않은 기능 또는 목적 달성 경로를 제품 문구에 추가하는 실패가 남았다. 검증 완료 스킬로 배포할 근거는 부족하다.

2026-10-22에 합성 입력을 고정한 뒤 실제 새 모델 세션으로 비교했다. 요청 모델은 `gpt-6.1-sol`, 추론 설정은 `low`였다. 출력 이벤트에는 실제 런타임 모델명이 없어 실행 모델을 별도로 확인하지 못했다. 결과는 작성자가 원문과 대조해 의미를 검수했다. 단어 검색만으로 판정하지 않았다.

| 시험 | 대조 조건 | 명시적 가이드 제공 조건 |
|---|---|---|
| 최초 다섯 사례 | 다섯 사례 의미 보존 | 세 사례 보존, 승인→다운로드 관계 누락, 미확인 설정 화면 기능 추가 |
| 좁은 규칙 보완 뒤 두 사례 재확인 | 새 대조군 없음 | 승인 관계 보존, 미확인 화면 기능 단정은 지속 |
| 사실 목록→편집→새 주장 대조 절차로 수정한 뒤 네 사례 | 세 사례 보존, 설정 화면 기능 추가 | 세 사례 보존, 미확인 목적→이동 경로 추가 |

마지막 네 사례는 [regression-cases.json](regression-cases.json)에 있다. 원래 두 문제 사례와 그 전에 쓰지 않은 보고서·오류 사례 두 개로 구성했다. 사례와 의미 검수 기준은 생성 전에 고정했고, 정답이나 실패 진단은 생성 요청에 제공하지 않았다.

마지막 비교에서 두 조건 모두 승인 순서, 보고서의 이름·버전·날짜·수치와 미확인 상태, 오류 내역 이동을 보존했다. 버튼 사례에서 대조 조건은 도착 화면에서 Wi-Fi를 설정할 수 있다고 단정했다. 가이드 조건은 Wi-Fi를 켜려면 그 화면으로 이동하라고 썼다. 후자는 기능을 직접 단정하지 않아도 입력에 없는 목적 달성 경로를 제시하므로 보수적으로 통과시키지 않았다. 별도 확인 질문이 제품 문구의 미확인 단정을 정당화하지 않는다.

전체 가이드와 예문·출처를 사용자 메시지로 명시적으로 제공한 시험이다. 자동 스킬 검색·설치·로딩 시험이 아니다. 기본 컨텍스트와 전역 스킬 목록 제외를 완전히 확인하지 못했다. 각 조건 한 번이며 인과 효과·개선율·일관된 우열을 입증하지 않는다. 처음 대조군이 지킨 제한을 나중 대조군이 어겨 표본 변동성도 나타났다. 내부 사실 목록 작성이나 주장 대조 이행은 최종 출력만으로 확인할 수 없다.

결과는 원래 실패를 지우지 않고 유지한다. 제품 문구를 실제로 사용하기 전에는 새 기능·행동·원인·권한 주장을 입력과 대조해야 한다. 이 문서는 출력 품질의 보증이나 자동 배포 승인이 아니다.

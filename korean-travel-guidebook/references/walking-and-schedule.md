# 보행 추정·전체 일정 검토

전체 여행의 무리 여부를 먼저 평가하고 수정한 뒤 첫날 HTML을 완성할 때 읽는다. 보행량은 계획용 추정이며 실제 계측이나 안전을 보증하지 않는다. 1만 보는 의학적 안전 기준이 아니라 이 스킬의 사용자 요청 상한이다.

## 계산 범위와 전제

하루는 숙소 문을 나가서 돌아올 때까지다. 이동일은 출발 숙소부터 도착 숙소까지 공항·역·환승·호텔 내부를 포함한다. 관광지 사이 지도 거리만 합산하지 않는다. 동행자마다 보폭과 피로가 다르므로 성인 환산 걸음을 아이에게 그대로 적용하지 않는다. 가장 제약이 큰 동행인의 조건으로 경로를 짜고, 필요하면 동행인별 범위를 따로 낸다.

구간 장부에는 `구간·필수/선택/생략 / 이동 수단 / 시간 범위 / 보행 거리 근거 / 추정 걸음 하한·상한 / 경사·계단·서 있는 시간 / 앉는 휴식 / 입출구·승하차·엘리베이터 / 불확실성 / 생략 절감 시간·걸음`을 둔다.

- 외부 보행, 숙소 복도, 역·공항 내부, 환승, 입장 전후, 전시실 이동, 식당·화장실 우회, 대기열의 움직임, 길 찾기, 계단·경사를 빠짐없이 별도 합산한다. 이미 지도 거리에 들어간 구간은 다시 더하지 않는다.
- 보행 거리만 있으면 개인의 실제 관찰 자료가 있을 때 그 보폭 범위를 쓴다. 자료가 없으면 가정 범위를 공개하고 추정으로 표시한다. 하나의 보편적 보폭이나 만 보 환산 거리를 사실처럼 쓰지 않는다. `걸음 하한 = 거리 하한 / 보폭 상한`, `상한 = 거리 상한 / 보폭 하한`처럼 불확실성을 유지한다.
- 내부 거리·동선이 없으면 비슷한 장소를 몰래 대입하지 않는다. 공식 평면도·현장 자료를 찾고, 그래도 없으면 범위와 근거를 적는다. 범위를 정할 근거도 없으면 미확인으로 남기고 경로 축소·차량 대안을 제시한다.
- 계단·경사·더위·혼잡·서 있는 대기는 걸음 수가 작아도 부담이 크다. 걸음 수만으로 `아이에게 무리 없음`이라 판정하지 않는다. 임의의 계단 가중치를 실측 걸음과 섞지 않는다.
- 일일 합계에는 확인한 모든 구간과 아직 합산하지 않은 실내 이동·길 찾기의 별도 여유를 넣는다. 여유를 고정 비율로 숨기지 말고 범위·이유를 보인다. 한 구간의 불확실성을 상한과 여유 양쪽에 중복 반영했는지 확인한다.

## 판단과 조정

사용자의 하루 전체 상한 요구는 10,000보 이내이며 중심 목표는 7,000~8,000보다. 이 스킬의 보수적인 발행 판단은 추가 여유를 포함한 추정 상한이 10,000보 미만일 때만 통과시킨다. 정확히 10,000보인 계획도 여유를 더 확보하도록 조정한다. 합계는 `기본 경로 범위 + 미포함 여유 = 일일 계획 범위`로 표시한다. 단정적인 정확한 정수 하나보다 범위를 우선한다. 모든 필수 이동·휴식을 포함했는지 확인한다.

추가 여유를 포함한 일일 추정 상한이 10,000보 이상이거나 핵심 이동이 미확인이면 제약 충족으로 판정하지 않는다. 선택 방문을 줄이고, 택시·셔틀·엘리베이터·가까운 입구·숙소 복귀를 적용한 다음 다시 계산한다. 확인된 택시 승차·하차 위치와 접근 보행도 포함한다. 차량이 건물 입구까지 항상 들어간다고 가정하지 않는다. 사실로 확인되지 않은 요금·운행·앱 메뉴를 채우지 않는다.

각 선택 방문에는 생략 후 총량과 `약 몇 보·몇 분 절감`을 동일한 장부 기준으로 계산한다. 생략하면 다른 위치로 이동하게 되는 경우 단순히 그 방문 구간만 빼지 말고 연결 구간을 다시 계산한다. 취소 수수료·예약 불가역 조건이 실제로 확인되면 함께 표시한다. 예약 실행은 하지 않는다.

전체 일정 검토표는 날짜마다 `도착·출발/수면 기회/귀가와 다음 출발/보행 범위/차량과 환승/앉는 휴식/식사/아이·동행인 부담/예약·휴무 충돌/조정/미확인`을 담는다. 늦은 귀가 뒤 다음 날 이른 출발을 피한다. 고정 예약 때문에 피할 수 없으면 앞날 활동을 줄이고 그 제약을 사용자에게 확인한다. 적정 수면 시간을 나이만으로 임의 보증하지 않는다.

하루 브리핑에는 오늘의 필수, 선택·생략, 예정 귀가, 걷기 범위·여유·불확실성, 휴식, 예약 확인과 준비물을 짧게 쓴다. 각 이동은 `어디서 타고/어디서 내려/입구까지 어떻게`를 설명한다. 식사와 앉는 휴식은 시간표에 예약된 시간으로 넣는다. 단순 `틈틈이 쉼`으로 대체하지 않는다.

## 현장 조정

- 비·폭염·강풍 등 날씨 대안은 가까운 실내 활동 또는 숙소 휴식과 차량 이동을 사용해 다시 계산한다. 먼 날짜의 기후와 실제 예보를 구분한다.
- 피로 대안은 선택 방문 생략, 앉아서 식사, 택시 귀가 등 구체적인 중단 지점과 경로를 제시한다. 아이·동행인의 상태가 계획보다 우선한다.
- 가족 구성에 맞게 말투·관찰 포인트·화장실·식사·건강·보행 조건을 바꾼다. 배우자와 10세 아이만 확인되면 부모님을 자동 추가하지 않는다. 부모님이 실제 동행하면 본인이 말한 조건을 확인하고 적용한다.

## 일정 검증 체크리스트

- [ ] 전체 여행부터 평가·조정했고 첫날 상세본은 그 결과와 일치한다.
- [ ] 숙소 출발~복귀와 공항·역·실내·식사·대기·계단·경사·우회를 포함했다.
- [ ] 추정 근거·보폭 가정·불확실성·추가 여유가 보이고 중복 합산이 없다.
- [ ] 사용자의 10,000보 이내 요구에 여유를 두기 위해 일일 추정 상한+추가 여유가 10,000보 미만이며 중심 목표 7,000~8,000보를 지향한다. 미확인 구간을 0보로 처리하지 않았다.
- [ ] 차량 승하차점·엘리베이터·입출구와 그 접근 보행을 포함했다.
- [ ] 필수/선택/생략과 생략 시 걷기·시간 절감을 다시 계산했다.
- [ ] 고정 예약·마지막 입장·휴무·식사·앉는 휴식·숙소 복귀 시간이 충돌하지 않는다.
- [ ] 늦은 귀가 다음 날 이른 출발과 누적 피로를 조정했다.
- [ ] 날씨·피로 대안도 보행·이동·휴식 조건을 만족하는지 검토했다.
- [ ] 단순 보행량으로 건강·안전이나 실제 만 보 이내를 보증하지 않았다.

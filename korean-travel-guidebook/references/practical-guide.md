# 별도 실전 안내

일정과 별도 섹션으로 제공한다. 방문 국가·여행 날짜·국적·환승 조건·동행 연령에 따라 공식 규정과 절차를 확인한다. 필요한 국적·체류 자격은 민감한 번호 없이 묻는다. 이 문서는 안내 작성이며 실제 계정 생성·인증·민감정보 입력·예약·결제를 실행할 권한은 따로 필요하다.

## 다룰 주제

1. 출입국·온라인 신고: 공식 URL, 적용 대상, 접수 가능한 시기, 동반 아동 등록, 완료 증빙, 수정·오류 복구. 여권번호·카드정보를 입력받지 않는다.
2. 공항: 입국심사→수하물→세관→공항 교통. 세관 신고 대상은 공식 근거와 확인일을 붙인다. 공항 간 차이, 터미널·승하차장·엘리베이터를 확인한다.
3. 도심 교통: 교통카드 구입·충전·환불·아동 요금, 지하철 개찰/환승/출구, 택시 승하차·차종·목적지 표시, 지도 앱과 오프라인 한계. 출구 번호를 추정하지 않는다.
4. 결제: 지원 카드·계정 가입·본인 인증·외국인 지원·수수료·결제 완료 및 취소 확인. 현금 예산은 검증한 고정비/추정 변동비/비상 여유를 나누며 현지 통화와 환율 기준일을 쓴다.
5. 통신: eSIM 기기 호환/잠금·개통 시점·데이터/전화/SMS 범위, 로밍 대안, 인증문자 수신 조건. QR이나 활성화 코드·OTP는 수집하거나 예시로 노출하지 않는다.
6. 예약/입장: 공식 예약처·이름 표기·시각/시간대·취소·아동 조건·증빙. 티켓·계정 접근은 별도 허가 없이 실행하지 않는다.
7. 현지 생활: 시차, 전압·콘센트, 화장실·급수·편의시설, 검증한 긴급 연락처와 위치 설명 문장, 짧은 현지어. 응급 번호는 국가 확인 전 채우지 않는다.

## 절차 카드 형식

- 적용 앱/웹, OS/버전·언어, 확인일, 공식 근거와 열람 범위를 적는다.
- 확보 가능한 **실제 화면** → **누를 버튼의 정확한 표기** → **명확히 가상이고 비민감한 입력 예시** → **완료 확인 기준** → **오류 원인/공식 복구 경로** 순서로 작성한다.
- 실제 화면을 확보하지 못하면 “화면 미확보·메뉴 미검증”이라고 표시한다. 화면을 합성하거나 미확인 버튼명을 확정하지 않는다. 공개 공식 설명이 확인된 범위만 적는다.
- 모든 화면의 촬영/재사용 권리·개인정보를 확인한다. 입력 예시는 이름 `EXAMPLE USER`, 목적지 `가상 예시 숙소`처럼 분명히 구분하고 실제 서비스에 제출하지 않는다.
- 접속 제한·로그인 요구가 있으면 우회하지 않고 공식 링크와 확인 필요 부분을 제공한다.

# Label the claim

Label each claim Verified (with method), Read, Inferred or Question. In Korean use 확인 / 읽음 / 추정 / 질문. A number needs its limiting factor and proof that it measured the intended work.

**Why:** An unlabeled sentence reads as a verified fact. The reader cannot see which claims rest on a run and which rest on a guess.

**How:**
- Verified: you ran it and observed the result. Name the method in the same sentence.
- Read: you saw it in code, documents or logs, but did not run it.
- Inferred: you concluded it from other facts. Name those facts.
- Question: you do not know, and the answer changes something.
- For each number, state the conditions, the limiting factor and how you know it measured your change.

**Stop:** Do not present Read or Inferred claims as Verified. Do not report a number whose measurement you did not check.

**Evidence of use:** labels on report rows, memo rows and record lines; the limiting factor next to each number.

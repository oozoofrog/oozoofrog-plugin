### Prototype
**You own the decision, not the code. The prototype is throwaway.**

1. Name the decision that the prototype settles. If there is no decision, build no prototype and use `playbooks/build.md`.
2. Build in the session scratch directory, outside the repository. Use the lightest stack that shows the question. Write no tests.
3. Put 2–3 variants behind one switch, such as a flag, a key or a button.
4. Observe each variant on the matching surface: screenshots for a visual question, output or timing for a behavioral one.
5. Recommend one variant. Record it as AI-proposed, with its evidence. Hand off to `playbooks/build.md` or `playbooks/design-docs.md`.
6. Run `playbooks/wrap-up.md`.

**Report:** variants, evidence, tradeoffs, recommendation, scratch path. State that the prototype is throwaway.

# {{project}} 위키

{{project}} 작업의 성공과 실패, 지시와 대응의 교훈, 프로젝트 지식을 모은다. 쓰는 법은 [[위키 사용법]]에 있다.

## 먼저 볼 것
- [[효과적인 지시 방법]]: 사용자가 일을 맡길 때 쓰면 좋은 방식
- [[에이전트 대응 원칙]]: 에이전트가 지시를 받았을 때 지킬 것
- [[받은편지함]]: 아직 정리하지 않은 한 줄 메모

## 폴더
| 폴더 | 내용 |
|---|---|
| `10 작업 기록` | 요청 하나에 노트 하나. 요청 원문, 결과, 양쪽 회고 |
| `20 교훈` | 교훈 하나에 노트 하나. 후보 → 채택 → 규칙화 → 폐기 |
| `30 지시 가이드` | 채택된 교훈 중 사용자 쪽 |
| `40 대응 가이드` | 채택된 교훈 중 에이전트 쪽 |
| `50 지식` | 제품, 구조, 동기화, 성능, 검증, 배포, 결정, 문제, 용어 |
| `60 회고` | 기간마다의 회고와 교훈 상태 정리 |
| `90 템플릿` | 노트 템플릿 |

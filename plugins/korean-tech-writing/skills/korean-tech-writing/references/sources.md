# 출처와 한국어 적용의 한계

## 출처

- [RFC 2119](https://www.rfc-editor.org/rfc/rfc2119): MUST, MUST NOT, REQUIRED, SHALL, SHALL NOT, SHOULD, SHOULD NOT, RECOMMENDED, MAY, OPTIONAL의 뜻을 정한다. 6절은 요구어를 상호 운용이나 피해 방지에 실제로 필요한 곳에만 쓰라고 한다.
- [RFC 8174](https://www.rfc-editor.org/rfc/rfc8174): 대문자로 쓴 요구어만 RFC 2119의 뜻을 가진다고 정한다.
- [ASD-STE100](https://www.asd-ste100.org/): 기술 문서용 영어 통제 언어 규격이다. ASD가 관리하며 작성 규칙과 통제 사전으로 이루어진다.

## 이 스킬이 정한 것

다음 내용은 RFC나 ASD가 정한 것이 아니다. 이 스킬의 편집 기준이다.

- 한국어 요구 형태 다섯 가지와 문서 첫머리 선언. 한국어에는 대문자가 없으므로 고정된 형태와 선언으로 RFC 8174의 대문자 규칙을 대신한다.
- MAY를 "…해도 된다"로 쓰고 "할 수 있다"를 능력과 가능성에만 쓰는 구분.
- 추적용 영어 표지를 괄호로 덧붙이는 방식.
- STE 원칙의 한국어 적용. STE의 단어 수 기준은 한국어 어절과 1:1로 대응하지 않으므로 숫자 기준을 두지 않는다. 통제 사전은 한국어로 옮길 수 없으므로 "한 개념에 한 용어"와 용어 표로 대신한다.
- 경고와 주의의 구분과 경고의 위치.
- 확인 수준 표. 이 저장소 사용자의 작업 원칙에서 가져왔다.

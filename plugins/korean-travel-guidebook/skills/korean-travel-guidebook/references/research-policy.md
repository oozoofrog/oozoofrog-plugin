# 자료 신뢰·권리·현장 정보 확인

여행 가이드북을 조사할 때 읽는다. 이 문서는 조사 기준이며 특정 여행지의 운영·입국 정보를 확인한 결과가 아니다.

## 사실 확인 기록

각 중요한 주장에 `주장 ID / 대상·공식 명칭 / 내용 / 사실·후기·추정·미확인 / 원문 URL / 실제 읽은 범위 / 게시·갱신일 / 확인일 / 적용 여행일·요일 / 충돌·추가 확인`을 기록한다. 확인일과 여행일을 혼동하지 않는다. 검색 결과 요약만 읽었다면 `검색요약만 확인`으로 쓴다. 본문을 읽었다고 기록하지 않는다. 첨부자료도 현재 운영기관의 자료로 재검증한다.

1. 운영시간·휴무·요금·아동 연령·예약·마지막 입장·정비는 운영기관 공지와 공식 예매 페이지를 먼저 본다. 일반 운영시간보다 여행일 특별 공지가 우선한다. 날짜의 현지 요일·공휴일·계절·시간대를 확인한다. 가격에는 통화·세금·적용 연령·기준일을 붙인다.
2. 입국·온라인 신고·수하물·세관·환승 규정은 목적지 정부·출입국·세관·공항·해당 항공사의 담당 자료로 확인한다. 국적·여권·체류목적·경유·여행일 조건이 없으면 확정할 수 없는 부분을 표시한다. 민감한 여권번호를 대화에 요구하지 않는다.
3. 교통은 운영사·역 안내도·승하차장·엘리베이터 위치·운행일·막차·공사를 확인한다. 지도의 건물 중심 핀을 출입구나 택시 승차점으로 대체하지 않는다.
4. 역사·인물·연대·규모 수치는 박물관 소장품 설명·유산 관리기관·학술기관 원문을 우선한다. 한국어 역사·여행 자료도 병행한다. 널리 쓰는 한국어 이름과 현지명을 함께 적고, 옛 이름과 현재 장소를 연결한다. 전설은 전설로, 해석은 해석으로 쓴다. 규모 비교는 같은 단위·범위·시점이 맞을 때만 한다. 한국사 동시대 비교가 이해를 돕는 경우 정확한 시기와 차이를 표시한다.
5. 네이버 후기는 조사 시점 최근 1년 내 게시물을 우선 탐색하되 게시일과 실제 여행일을 별도로 확인한다. 최신 게시물도 오래된 여행일 수 있다. 체감 혼잡·보행·아이 반응은 `후기`로 표시하고 운영 사실을 대체하지 않는다. 접근 제한이면 제한과 미확인 범위를 기록한다. 다른 공개 자료로 계속 진행하며 로그인·차단을 우회하지 않는다.
6. 여행일이 예보 범위 밖이면 기후·평년 경향과 예보를 구분한다. 기후 통계를 날짜별 날씨 예측으로 표현하지 않는다. 예보 갱신이 필요하면 확인 시점을 안내한다.

출처끼리 충돌하면 담당기관·적용일·갱신일·공지의 구체성으로 판단한다. 해결되지 않으면 일정의 안전한 대안을 사용하고 미확인으로 남긴다. 제작 중 조사충돌의 세부 이력은 본문 동선을 방해하지 않도록 참고자료 영역에 둔다. 현장 행동을 바꿀 핵심 주의는 본문에도 짧게 남긴다.

## 사진·유물·지도·폰트

- 사진은 바로 그 건물·공간·유물인지 소장기관·소장번호·촬영 방향·시기·설명으로 대조한다. 비슷한 다른 사원·복제품·다른 시대의 물건으로 대체하지 않는다. 캡션은 관찰할 부분과 현장에서 볼 위치를 설명한다. 필요하면 번호를 넣되 원본과 변경 내용을 기록한다.
- 사진마다 `원문 파일 페이지 / 제작자 / 작품명·소장번호 / 라이선스·버전 / 라이선스 원문 / 변경 내역 / 확인일 / 로컬 파일`을 남긴다. 무료로 보인다는 이유만으로 복사하지 않는다. 권리가 확인되지 않으면 이미지를 생략하고 누락을 밝힌다. 실제 사진이 없는 테스트에는 명확한 가상 도형만 사용한다.
- 공식 지도도 재배포 권리를 따로 확인한다. 권리가 없으면 링크와 원본 접근법을 제공한다. 직접 그린 동선 그림에는 `동선 개념도·축척 없음·실제 지도 아님`을 표시한다. 문과 통로의 실제 위치를 모르면 기호로 단정하지 않는다. 가짜 앱 화면·가짜 길찾기를 만들지 않는다.
- Google Maps URL을 문법에 맞게 만들었다는 사실은 대상·입출구 검증이 아니다. 열람 가능한 지도와 공식 주소·입구 설명을 대조하고, 정확한 입구·역 출구·탑승 위치 및 확인일을 남긴다. 가능한 확인된 Place ID를 사용한다. 미검증 링크는 `검색용·입구 미확인`으로 표시하며 `검증 지도`로 부르지 않는다. 네트워크·지역 지원 여부도 확인한다.
- OSM 데이터 이용 가능성과 공용 타일 서버 이용 조건은 다르다. `tile.openstreetmap.org`를 오프라인용으로 일괄 저장하지 않는다. 오프라인이 허용된 공급원 또는 권리가 확인된 지도·자체 개념도를 사용한다.
- 나눔고딕은 확인된 원본 폰트와 해당 저작권·SIL OFL1.1 전문을 함께 제공한다. 단순 CSS 지정은 폰트 내장이 아니다. 원본을 수정하면 Reserved Font Name 조건을 확인한다. 폰트 파일을 확보하지 못하면 대체 폰트와 미내장을 명시한다.

HTML의 참고자료는 출처·확인일을 보존한다. 요청받은 PDF에서는 일반 조사 출처 목록을 제외할 수 있지만 사진·지도·폰트의 의무 저작권 표시는 출력에서도 보존한다. 이 의무를 CSS로 숨기지 않는다. 오프라인 본문·사진·폰트와 온라인 지도·최신 공지·예약 페이지의 경계를 문서에 표시한다.

## 발행 전 체크리스트

- [ ] 동행인·연령·보행 조건이 확정됐거나 임시 전제가 명시됐다. 템플릿의 부모님 문구를 자동 적용하지 않았다.
- [ ] 여행일 현지 요일·공휴일·정비·특별휴무·최종입장·아동 조건을 대조했다.
- [ ] 주장 유형과 확인일, 본문 열람 여부가 출처 기록과 일치한다.
- [ ] 후기 게시일과 실제 여행일을 구분했고 검색요약을 본문 확인으로 표시하지 않았다.
- [ ] 역사·규모 수치의 출처와 전설·해석 구분, 쉬운 설명·필요한 연표·관계도가 있다.
- [ ] 사진의 정확한 대상, 권리, 관찰 캡션, alt가 확인됐다. 미확인 이미지를 실제처럼 넣지 않았다.
- [ ] 지도 링크의 대상·입출구를 검증했거나 검색용·미확인으로 표시했다.
- [ ] PDF에서 제외할 조사 출처와 유지할 의무 저작권 표시를 구분했다.
- [ ] 현장 검색표에 한국어·현지어·영어, 입출구·역·승하차점, 복사용 이름, 직원에게 보여줄 문장이 있다. 미확인 번역을 확정하지 않았다.
- [ ] 실전 절차에는 실제 확인한 화면·버전·확인일, 누를 버튼, 명확한 가상 입력 예시, 완료 확인, 오류 대안이 있다. 화면 미확인 부분은 확인 필요로 남겼다.
- [ ] 출입국·신고·공항·도심 교통·교통카드·지하철·택시·지도·결제/인증·현금·eSIM/로밍/문자인증·예약/입장·시차·전압·화장실·응급·현지어 항목의 확인 여부가 보인다.

모바일 검수는 320 CSS px 폭의 본문 재배치, 키보드 동작, 이미지 대체 텍스트를 포함한다. WCAG2.5.8은 예외를 둔 24×24 CSS px 최소 목표를 정의한다. 이 가이드북은 주요 조작부에 44px를 권장한다. 44px를 해당 최소 기준 자체로 설명하지 않는다. 정적 코드 검사만으로 접근성 전체 준수를 주장하지 않는다.

The Swift controller, fixture, tests, scripts and companion skill were authored for this project. `Package.swift` declares no third-party package dependencies. No vendored third-party source, model weights, credentials or service client SDKs are included.

The executable links to Apple system frameworks. Those frameworks and the Xcode/Swift toolchain are supplied separately by their owners. Window-local pointer routing uses an Apple-private SkyLight symbol and an undocumented event field; see the README for compatibility and distribution limits.

These services, executable distributions and their authentication files are not redistributed here. The repository does not imply affiliation or endorsement.

## Team coordination

Use the team-coordination skill when this workflow is enabled. The leader coordinates; an execution owner performs substantive work; an independent reviewer checks current evidence. Assign one owner per canonical write path. Preserve uncertain outcomes and block duplicate retries until reconciled.

Use one project task record. Preserve goal, constraints, decisions and rationale. Acknowledge the current role/context packet; refresh after instruction changes, resume, compaction or handoff. Pass relevant context and changes, not full conversation copies.

Use explicit supported model IDs, exact returned model receipts and bounded concurrency/token reservations. Never silently substitute a model. Stop repeated reviews at the configured limit. Report observed usage separately from estimates; reservations are not exact billing caps.

Managed gates apply only to this adapter; bypassing clients have advisory policy. Disk installation does not prove hot reload or adoption. Report created, tested, reviewed, installed, discovered and acknowledged states separately. This policy grants no new action permissions or security access.
